# Spécifications

Ce dossier contient les spécifications produites par l'agent `analyste` (commande `/spec`, station 3).

- Une spécification par tâche : `specs/TASK-XXX.md`.
- Une spécification décrit **le comportement attendu** (critères d'acceptation vérifiables), pas l'implémentation.
- Les tests de l'agent `testeur` sont dérivés de la spécification : un critère = au moins un test.
